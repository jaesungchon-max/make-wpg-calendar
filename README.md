# MAKE WPG Calendar — Stage 1 prototype

Next.js App Router, React, TypeScript, Tailwind CSS. Sample events only. No accounts, database, submissions, or email service connected.

## Run locally

1. Install Node.js 20.9 or later.
2. Open a terminal in this folder.
3. Run `npm install` once.
4. Run `npm run dev`.
5. Open http://localhost:3000 in a browser.

## Test

- Navigate between months with arrows, and swipe on mobile.
- Select October 15, 2026 to view four sample events.
- Select an event to see its details and return.
- Filter by ALL / TALK / EXHIBITION / OTHER.
- Search for a venue or keyword.
- Check desktop and mobile browser widths.
- Run `npm run build` before deployment.

## Deploy

Push this project to a private GitHub repository, import it into Vercel, and deploy using the Next.js defaults. Do not attach a production domain until the prototype is reviewed.

## Important

All listed events are fictional representative records for interface testing, not verified Winnipeg event announcements. The image areas are intentional placeholders. Submission and subscription controls are informational only.
